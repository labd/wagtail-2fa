## 2.0.0 - 2026-11-17
### Added
* Support for Wagtail 8.
### Removed
* Support for Python 3.10 and Python 3.11.0 to 3.11.4. Python 3.11.5 or newer is now required.
### Fixed
* The 2FA login form works again with django-otp 1.7.1 and newer. Users with more than one device now choose which device to use when they log in.
* The 2FA middleware no longer breaks requests to URLs that match no URL pattern, such as page previews.
* The 2FA code can now be entered with spaces, as authenticator apps often show it (for example "123 456"), both at login and when adding a device.
### Dependency
* Bump django-otp from 1.7.4 to 1.7.5
* Bump wagtail from 8.0 to 8.0.1
* Bump pytest from 9.1.1 to 9.2.0
